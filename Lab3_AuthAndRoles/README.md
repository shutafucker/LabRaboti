# Лабораторная работа №3: Авторизация админа и роли

## Описание
В систему добавлена аутентификация и ролевая модель доступа:
- Модель `User` с безопасным хранением хэшей паролей через `BCrypt.Net-Next` (соль, фактор 12).
- Окно входа `LoginWindow` перед отображением `MainWindow`.
- Роли:
  - `Admin` — доступны все действия: посадка игроков, закрытие сессий.
  - `Operator` — кнопки действий заблокированы в UI и валидируются на уровне логики.
- Кнопка выхода из учетной записи.

## Тестовые учетные записи (создаются автоматически при первом старте):
- Логин: `admin`, Пароль: `admin123` (Роль: Admin)
- Логин: `operator`, Пароль: `operator123` (Роль: Operator)

## Миграция
```shell
Add-Migration AddUsers
Update-Database
```
Или:
```shell
dotnet ef migrations add AddUsers
dotnet ef database update
```
