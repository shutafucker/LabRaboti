# Лабораторная работа №2: Журнал операций

## Описание
Связывание справочника (`Computer`) и журнала операций (`Session`). Реализована двухпанельная панель администратора:
- Слева список ПК с фильтрацией на лету (поиск по имени, «Только свободные», «Только VIP») и динамическим статусом («Занят» / «Свободен»).
- Справа история сессий выбранного ПК с длительностью и индикатором активности.
- Снизу действия: посадка игрока (с валидацией занятости) и завершение активной сессии.

## Миграция
В модели `Session` добавлено поле `EndTime`:
```shell
Add-Migration AddSessionEndTime
Update-Database
```
Или:
```shell
dotnet ef migrations add AddSessionEndTime
dotnet ef database update
```
