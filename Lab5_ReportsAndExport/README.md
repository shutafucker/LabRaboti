# Лабораторная работа №5: Отчёты и экспорт

## Описание
Финальная работа, объединяющая весь функционал управления клубом «CyberArena» и добавляющая аналитическую подсистему:
- DTO-модели для аналитики: `ReportSummary`, `PcUsageRow`, `DailyRow`.
- `ReportService` с методами агрегации данных по закрытым сессиям:
  - `GetSummaryAsync`: общее число сессий, часов, средняя длительность, лучший игрок периода.
  - `GetTopPcsAsync`: топ-5 ПК по количеству игровых сессий.
  - `GetDailyAsync`: динамика по дням.
- Окно `ReportsWindow` с выбором периодов («Сегодня», «Неделя», «Месяц»), визуальной карточкой сводки и двумя таблицами статистики.
- Экспорт отчёта в CSV с кодировкой UTF-8 с BOM (`new UTF8Encoding(true)`) и разделителем `;` для идеального открытия в Microsoft Excel без кракозябр.

## Запуск и развертывание:
1. Выполните скрипт `database_setup.sql` в панели Supabase SQL Editor.
2. Откройте проект в Visual Studio и запустите по F5.
3. Войдите под `admin` / `admin123`.
